# Education RAG Documents

Structured repository for Leaving Certificate educational source documents.

## Purpose

This repository stores source-of-truth educational documents for future AI/RAG systems.

## Includes

- Curriculum specifications
- Past papers
- Marking schemes
- Formula tables

## Structure

- docs/ -> raw source documents
- processed/ -> future extracted text/chunks
- metadata/ -> future metadata/index files
- scripts/ -> future processing scripts

## Naming Convention

Use filenames such as:

paper-1.pdf
paper-1-marking-scheme.pdf
paper-2.pdf
paper-2-marking-scheme.pdf
