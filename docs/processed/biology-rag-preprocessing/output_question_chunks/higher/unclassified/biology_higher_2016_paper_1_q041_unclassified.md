# Question

4.  Name another part of the ear that has a function similar to that of the stirrup.

# Marking Scheme

4.                                                 5(3) + 5(1)

       (a)    (i)   Chance roan × white → red: 0%

                (ii)   Chance roan × red → red: 50%

                (iii)  Chance roan × roan → red: 25%

      (b)    (i)   Sex-linkage:   When genes are carried on the sex (or X or Y) chromosome(s)

                (ii)  More likely:    Males

                (iii)  Male genotypes and phenotypes:

                Genotype:    XnY–

                Phenotype:    Sufferer


                Female genotypes and phenotypes:

               Genotype:   XnXn                      Genotype:   XNXn

               Phenotype:   Sufferer        OR   Phenotype:   Normal

                             (or lethal for haemophilia)



                   Explain:    Male only needs to inherit the recessive allele (from mother)

                          or female must inherit the recessive allele from each parent.

                          or female may be a carrier

                          or female recessive homozygote is a sufferer (or lethal for haemophilia)
