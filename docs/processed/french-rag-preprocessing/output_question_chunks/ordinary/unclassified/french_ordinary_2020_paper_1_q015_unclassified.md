# Question

1.   Trouver la bonne destination

     Si vous souhaitez faire la fête, pensez à Dublin ou Barcelone, des villes très fréquentées
    par les jeunes. Si vous n’avez pas un grand budget, allez dans une ville comme
    Dubrovnik ou Izmir pour le coût peu élevé de la vie. Partir seul dans le but d’être isolé, il
    vaut mieux voyager hors saison. Vous avez envie de profiter de la plage sans personne
    autour de vous ? Alors visitez Malte où de nombreuses plages désertes vous attendent.
