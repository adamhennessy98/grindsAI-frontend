# Question

4.   Préparer sa valise pour un voyage solo

     Si vous avez peur de vous ennuyer, n’oubliez pas de glisser un ou plusieurs livres
    dans vos bagages. Ces livres vous occuperont pendant que vous faites la queue devant
   un musée ou pourront vous divertir pendant un repas dans un restaurant.
     Si vous partez voyager à la montagne, pensez à vous équiper convenablement : cartes de
    randonnée, boussole, vêtements chauds, téléphone portable, matériel de premier secours.
