(b)
     Functional testing tests whether the system meets its requirements whereas non-
       functional testing tests how well those requirements are met e.g. performance, usability,
         reliability, scalability and other non-functional aspects of the software system
     Functional testing should be carried out before non-functional testing.
     Examples of functional testing include unit testing, smoke testing, integration testing,
      white box testing, black box testing, user acceptance testing and regression testing.
     Examples of non-functional testing include performance testing, stress testing,
        installation testing, usability testing, security testing, penetration testing and
       compatibility testing.
