In web design, colours are often represented using a hexadecimal code
which defines the red, green, and blue (RGB) components of the colour.

For example, the hex colour #0A33F0 represents a shade of blue, where:

      the first two characters (0A) represent the red component.

      the next two characters (33) represent the green component.

      the last two characters (F0) represent the blue component.

Each component is represented in hexadecimal from 00 to FF (0 to 255 in decimal).
