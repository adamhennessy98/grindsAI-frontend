possible due to the protocols that it uses.

Others: Echo, finger, Gopher, POP3, DNS, UDP
 Protocol     Purpose
 HTTP        High level protocol used to support the exchange of WWW documents (typically
            HTML)
 HTTPS      HTTP + added security layer / encryption-decryption
 TCP        Low level protocol – sender breaks messages into packets hands over to IP (for
               routing) and re-assembles and orders at the destination
 IP           Responsible for the routing of packets from source/sending process/device to
               destination process/device via a network of inter-connected computers/devices
 VOIP       The transmission of voice over IP
