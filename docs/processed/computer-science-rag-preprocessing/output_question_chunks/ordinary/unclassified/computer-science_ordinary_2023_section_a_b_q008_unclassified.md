# Question

Question 3

Using either a flowchart or pseudocode, create an algorithm which must do the following:
     Ask the user to input three separate numbers
     Work out the average of the three numbers
      Print the average of the 3 numbers

# Marking Scheme

Question 3                                                             6 marks


Pseudocode Example

input num1
input num2
input num3

average = (num1 + num2 + num3) /3

print average

Flowchart Example





Candidates can use either pseudocode or a flowchart, as long the process can be followed/
understood.
Attempt to input number(s)      1 mark OR 3 separate numbers input  2 marks
Attempt at calculating average   1 mark OR average calculated correctly 2 marks
Print / output of average        1 mark
All steps in correct logical order   1 mark
