# Marking Scheme

Question 2

      Accessibility: Cloud storage allows you to access your files from anywhere with an
       internet connection.
     Backup and Security: Files stored in the cloud are often automatically backed up and
       protected with advanced security measures.
      File Sharing and Collaboration: Cloud storage makes it easy to share files and collaborate
      with others.
     Automatic Updates: Cloud storage services often come with automatic software updates
      and maintenance.
     Disaster Recovery: In case of a local hardware failure (e.g., a damaged hard drive), cloud
       storage ensures that your files remain safe and recoverable.
     Cost Efficiency: With cloud storage, you only pay for the storage you use, avoiding the
       upfront cost of purchasing external hard drives or other local storage devices.
