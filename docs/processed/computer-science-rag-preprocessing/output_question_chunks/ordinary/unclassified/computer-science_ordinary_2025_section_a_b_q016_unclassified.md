# Question

Question 12

A piece of Python code is displayed below.

 1  myNum = "6"
 2  result = myNum + 3
 3  print (result)

When the code is run in an integrated development environment (IDE), it produces the following
error:
 TypeError: can only concatenate string (not "integer") to string

Explain why this error has occurred and how it could be fixed.
