(b)                                                          16 marks (6, 6, 4)
    (i)                                                         6 (3, 3) marks

Application Layer: This is to provide the programs and apps that people use to do specific tasks
on a computer or device. This includes things like web browsers, email clients, and games. It’s
what we directly interact with.

Hardware Layer: The purpose of the hardware layer is to provide the physical parts of a
computer, like the processor, memory, and storage. These components make it possible for all
the software to run and do tasks.
