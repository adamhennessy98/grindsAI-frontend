# Question

5. La tradición de los deportes irlandeses como el hurling y el futbol gaélico no se acabó. Todos los fines
  de semana se organizaban partidos contra otros equipos de irlandeses que vivían en Argentina. Pero
  para fomentar más esos deportes, a partir de 2009, el club inició un renacimiento del hurling.
  Empezaron a realizar campamentos de verano, con estrellas del hurling que venían de Irlanda. Además,
  construyeron un campo especial para deportes gaélicos.
