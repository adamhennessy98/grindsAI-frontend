# Question

4.  Los pasajeros que quieren viajar en globo deben estar en buena salud y no tener miedo a
  volar. Se recomienda llevar ropa cómoda y calzado adecuado como zapatillas de deporte para
 andar por el campo. Para la seguridad de todos hay algunas reglas, por ejemplo: no se permite
 beber alcohol, tomar drogas, o fumar tabaco en el globo.
