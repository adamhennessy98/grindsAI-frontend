A cascade chart (Gantt chart) is a type of bar chart which may be used to represent a project’s
schedule. The duration of each activity is represented by the width of the horizontal bar for that
activity, with time on the horizontal axis. The float time for an activity is represented by a
rectangle drawn using dotted lines to the right of the bar for that activity. The top row of a
cascade chart is used for a critical path.

(iv)  Draw a cascade chart or similar bar chart to represent the schedule for this project.
