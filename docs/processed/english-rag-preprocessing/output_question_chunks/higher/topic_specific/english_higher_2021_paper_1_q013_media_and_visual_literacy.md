# Question

5.    In TEXT 2, Doireann Ní Ghríofa alludes to the importance of bees in medieval Ireland.

      Write a fable or fairy-tale, set in ancient Ireland, in which a bee or bees feature prominently.

# Marking Scheme

5.     In TEXT 2, Doireann Ní Ghríofa alludes to the importance of bees in medieval Ireland.

     Write a fable or fairy-tale, set in ancient Ireland, in which a bee or bees feature
      prominently.

     Candidates should write a fable or fairy-tale, set in ancient Ireland, in which a bee or bees
      feature prominently. Allow for a broad interpretation of both fables and fairy-tales and
      for a wide variety of responses.
