# Marking Scheme

Question 7

A.   Ordnance Survey Map

     Examine the 1:50 000 Ordnance Survey map and legend accompanying this paper.
    Draw a sketch map of the area shown to half scale.
    On it, correctly show and label each of the following:

          • A railway line
          •  The N59
          •  The R335
          •  The built up area of Westport.
                                                                         [20m]

      Sketch Outline                     4 marks
     4 features @ 4 marks each:           Shown 3 marks (graded 3/1/0)
                                              Label 1 mark

      If sketch is traced or only a section of the map is drawn, lose 4 marks for
          sketch outline and lose 3 marks for showing per item. Allow naming marks only.
      Sketch outline means to half scale. Required size is 12cm x 9cm [allow a
          difference of up to ½cm]. The sketch must have four sides drawn.
      If the aerial photograph is used instead of the Ordnance Survey map 0 marks.
      Labels may be written on the sketch map or in a key.
      There must be an attempt to show feature for naming marks to be awarded. If
          not shown, 0 marks for naming.
      The features must be labelled on the sketch or in a key. If not labelled, 0
         marks for showing.
