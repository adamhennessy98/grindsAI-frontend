# Question

      Examine the photographs below and answer each of the following questions.

         (i)     Indicate whether each of the following statements is true or false, by circling the
               correct option in each case.

                (a)    The rock type in the photograph is
                     limestone and it is a permeable rock.

                  True               False




               (b)   The rock type in the photograph is slate
                  and it was formed from lava cooling.

                  True               False




                (c)    The rock type in the photograph is marble
                  which was once limestone or chalk but
                 was changed by great heat and/or pressure.

                  True               False




               (d)    The rock type in the photograph is basalt
                   and it can be found in Co. Antrim.

                  True               False
