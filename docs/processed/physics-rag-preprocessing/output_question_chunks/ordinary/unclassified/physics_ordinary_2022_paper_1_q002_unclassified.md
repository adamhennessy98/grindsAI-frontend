# Question

1.   A student carried out an experiment to measure the velocity of an object.

        (i)   Draw a labelled diagram of the apparatus used to measure constant velocity.      (12)

         (ii)   Indicate on the diagram what distance the student measured.

         (iii)  Describe how the student measured the time.

       (iv)   State the formula used to calculate the velocity.                                   (12)

     The student then used the apparatus to measure the acceleration of the object.

       (v)  What changes did the student make to the apparatus?

       (vi)  What measurements did the student take to calculate acceleration?

        (vii) How did the student use these measurements to calculate acceleration?

        (viii) State two precautions that could be taken to improve the accuracy of either of these
           experiments.                                                                      (16)
