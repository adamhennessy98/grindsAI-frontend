# Question

2.   An experiment was set up to establish the calibration curve of a thermometer.


        (i)   Draw a labelled diagram of the apparatus used in this experiment.                (12)

         (ii)  What measurements were taken during this experiment?                            (9)

         The table shows the data recorded during the experiment.


       Temperature (°C)                0     20     40     60     80     100
       Value of thermometric property    10     25     60     100    160    200


         (iii)  Use the data in the table to draw a graph, on graph paper, to establish the
            calibration curve. Put temperature on the horizontal (X) axis.                     (12)

       (iv)  Use your graph to determine the temperature when the value of the
          thermometric property is 75.                                                           (7)
