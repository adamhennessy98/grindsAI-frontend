# Question

3.   A student carried out an experiment to measure f, the focal length of a converging lens.

        (i)   Draw a labelled diagram of the apparatus used in this experiment.

         (ii)  On your diagram, indicate and label the object distance u and the image
           distance v.                                                                         (18)

         (iii)  Name the instrument used to measure the object distance and the image distance.

       (iv)  How did the student know that the correct image distance had been found?

       (v)   State the formula used to calculate f.

       (vi)  The student placed an object 16 cm in front of the converging lens.  It produced an
          image at a distance of 48 cm from the lens. Calculate the focal length of this lens.

        (vii) Why will this experiment not work if the object is placed very close to the lens?    (22)
