# Question

Section C - Options - Answer any one of the five optional questions.

Option 1 - Applied Control Systems - Answer 1(a) and 1(b)

1(a)  Robo-Deck is a device that can be used to clean and protect outdoor decking. It can be
    programmed to carry out preventative maintenance every few weeks, keeping the deck in
      pristine condition all year round.

        (i)   Suggest two advantages of using an automated deck
           cleaning device.

        (ii)   Briefly describe one other household device that
          operates like the Robo-Deck.

1(b) The image shows Robo-Deck cleaning a deck. As the brushes at the front clean the deck,
     a wood stain is sprayed from the back to protect the deck.

        (i)   Complete the flowchart, shown, to operate the
          Robo-Deck in the following sequence:

          •   The system is powered on
          •   The motor activates, moving the Robo-Deck
              forward for 15 seconds
          •   At the same time, the stain sprayer comes on for 15 seconds
          •   The motor and the sprayer stop.                                                                                      Start

        (ii)   Suggest a modification of the flowchart to alert the user

         (iii)  Name a suitable sensor that could be used to detect an

Answer 1(c) or 1(d)
