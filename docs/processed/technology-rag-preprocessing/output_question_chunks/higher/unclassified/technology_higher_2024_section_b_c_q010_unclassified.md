Option 3 - Information and Communications Technology - Answer 3(a) and 3(b)


      3(a)  Soccer star Cristiano Ronaldo as well as celebrities like Kylie Jenner and Selina Gomez have
           established a reputation as social media influencers.

                 (i)  Outline one benefit and one drawback of social influencing.

                  (ii)  Explain the social media influencer terms; reels, endorsements,
             and affiliate links.

      3(b) The specification for the Samsung Galaxy S22 ultra smartphone includes fast charging,
          expandable storage and a quad camera featuring an LED flash, auto-HDR which will take 4K
           videos at 30/60 fps and 8K videos at 24 fps.

                 (i)  Explain the phone feature 4K videos at 30/60 fps.

                  (ii)  Describe, with examples, each of these phone protection systems:
                •  Secure enclave for biometric data
                •  Secure communication protocols
                • Remote tracking and wiping.

                  (iii) Outline two advantages of data transfer using USB Type-C.


    Answer 3(c) or 3(d)


      3(c)  Secure connection to the internet is extremely important when carrying out financial
           transactions online or using banking apps.

                 (i)  Explain each of the following in relation to secure connections:
               • Data encryption
               • VPN
               •  Multiple firewalls.

                  (ii)  Explain the term network eavesdropping and the possible consequences for a business.

                              OR


      3(d)  (i)   Online advertising commonly incorporates images, video, and sound.
                Give a typical file extension for each of the elements listed above.


                  (ii)  Outline the function of any two of the following types of server:
                •  Domain Controller
                •   File Server
                •  Application Server.
