# Marking Scheme

4.   The guitar amplifier shown may typically contain a Darlington pair.

        (i)  Name the main electronic component used in a Darlington pair.
            Transistor.

        (ii)   Outline how a Darlington pair works.
        A Darlington pair is a configuration of two bipolar transistors
            (typically NPN type) connected in a way that amplifies the overall current gain of the
            pair. The Darlington pair is commonly used in electronic circuits where high current
           gain is achieved by combining the current gain of both transistors.
