# Marking Scheme

4.     (i)  Name the mechanism shown.

       Worm and wormwheel



         (ii)  Explain the self-locking feature of this mechanism.

        The driving motor is attached to the worm, this will
          drive the wormwheel with a speed reduction.
        The wormwheel will not drive the worm creating a
        mechanism that will allow movement only when the
       worm is driving.
